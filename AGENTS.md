# Working with MechCurve

Use the installed CLI or the local stdio MCP server to inspect the acquisition directory, analyze it, and verify the returned run. Read the status and any failed records before reporting results. Link the campaign PDF, specimen sheets and cycle tables in the verified delivery.

Use the acquisition-relative record ID and original source row for measurements and added interpretations. Distinguish the force peak, loading reversal and unload endpoint. Preserve the origin of instrument markers, experimenter notes and observations. Only group resumed acquisitions or independent replicates when specimen identity supports the grouping.

Treat input files as read-only. Place derived output in a separate versioned directory. When a dependent metric is unavailable, identify the available measured rows and report independent metrics normally.

For unfamiliar acquisitions, inspect the source channels and protocol catalog before assigning a method. A wide table can be reported in its measured coordinates. Supply a fixture, control interval or specimen identity only when supported by the experimental record. Preserve declared units, source rows and acquisition order when reporting conditional properties.
